# QuickNotes

QuickNotes is a simple and responsive note-taking web application that allows users to create, categorize, search, delete and store notes directly in their browser. The application uses HTML5 for semantic structure, CSS3 for responsive styling and JavaScript for note management, validation, search and localStorage persistence.

## Features

- Add new notes
- Personal, Work and Study categories
- Character validation with a 200-character limit
- Delete individual notes
- Search notes in real time
- Case-insensitive search
- Display the number of saved notes
- Save notes using browser localStorage
- Load notes automatically after refreshing the page
- Responsive mobile layout
- Category-specific visual styles
- Clear All notes option with confirmation
- Accessible form labels and semantic HTML
